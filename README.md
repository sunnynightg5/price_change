# سامانه قیمت استودیو عکاسی سبز

برنامه ویندوزی (Delphi 10 Seattle / VCL) برای مدیریت قیمت‌ها، محاسبه سفارش و صدور فاکتور
استودیو عکاسی سبز. داده‌ها از جداول `Price` و `person` پایگاه داده SQL Server با نام `SABZ` خوانده می‌شوند.

## صفحات

| میان‌بر | صفحه | کاربرد |
|---|---|---|
| F1 | داشبورد | آمار، دسترسی سریع، **تاریخچه آخرین تغییرات قیمت**، راهنمای کدها |
| F2 | جدول قیمت | ماتریس خوانای قیمت هر سایز + **ستون سود چاپ مجدد** (قیمت − هزینه چاپ و لمینت) |
| F3 | ویرایش قیمت | ویرایش مستقیم، افزایش/کاهش درصدی با گرد کردن، نمایش **مقدار قبلی و درصد تغییر** |
| F4 | محاسبه سفارش | سبد سفارش، تخفیف مبلغی یا **درصدی** (`10%`)، حاشیه سود، فاکتور A5 |
| F5 | هزینه‌های تمام‌شده | هزینه چاپ/شاسی/لمینت برای ما (کدهای `p` / `s` / `l`) |
| F6 | مشتریان | **جستجوی هوشمند** با نام، موبایل یا کد ملی و انتخاب مشتری برای فاکتور |

## میان‌برهای صفحه‌کلید

- `F1` … `F6`: جابه‌جایی بین صفحات
- `Ctrl+S`: ذخیره (قیمت‌ها / هزینه‌ها / فاکتور، بسته به صفحه فعلی)
- `Ctrl+F`: رفتن به کادر جستجوی همان صفحه
- `Ctrl+R`: اتصال مجدد و بارگذاری دوباره قیمت‌ها
- `Ctrl+P`: چاپ فاکتور (در صفحه محاسبه سفارش)
- `Enter` در جستجوی لیست قیمت: افزودن ردیف اول به سبد — `Delete` در سبد: حذف ردیف

## امکانات نسخه ۳

- **رنگ‌بندی جدول‌ها واقعاً فعال شد**: رویدادهای رسم سلول قبلاً نوشته شده بودند اما به هیچ جدولی وصل نبودند.
- **جستجوی مقاوم**: «ي/ك» عربی و «ی/ک» فارسی، ارقام فارسی/عربی/لاتین و `10x15` / `10×15` / `10*15` یکسان در نظر گرفته می‌شوند.
- **مشتریان با جستجوی فازی**: اول جستجوی مستقیم در پایگاه داده، و اگر نتیجه کم بود نام‌های مشابه
  (با غلط تایپی) با فاصله Levenshtein پیدا می‌شوند. دوبار کلیک، مشتری را همراه موبایلش به فاکتور می‌برد.
- **تاریخچه قیمت**: هر ذخیره (ویرایش، هزینه، ورود از اکسل) در `PriceLog.csv` کنار برنامه ثبت می‌شود
  (تاریخ شمسی، ساعت، کد، قبلی، جدید، درصد، منبع) و در داشبورد نمایش داده می‌شود. فایل در اکسل هم باز می‌شود.
- **فاکتور بهتر**: شماره ردیف، ارقام فارسی، موبایل مشتری، **مبلغ به حروف**، جای امضا.
- **جلوگیری از گم شدن تغییرات**: هنگام خروج، بارگذاری مجدد، ورود از اکسل یا ذخیره هزینه‌ها،
  اگر تغییر ذخیره‌نشده‌ای باشد پرسیده می‌شود (ذخیره / نادیده گرفتن / انصراف).
- **فایل تنظیمات** `SabzPrice.ini` (نمونه: `SabzPrice.ini.example`): مسیر اکسل و رشته اتصال پایگاه داده؛
  اگر فایل اکسل پیدا نشود، برنامه محل آن را می‌پرسد و به خاطر می‌سپارد.
- جستجوی قیمت با ایندکس (Dictionary) به‌جای جستجوی خطی.

## راهنمای کدهای قیمت

| الگو | معنی |
|---|---|
| `10*15` | عکس هنری، چاپ مجدد |
| `10*15n` | عکس هنری، عکس جدید (فقط چاپ) |
| `10*15_` | شاسی و لمینت تنها |
| `10*15f` | هزینه هر چهره اضافه (روتوش) |
| `...i` / `...a` | آلبوم ایتالیایی / عکس مراسم عروس و داماد |
| `p10*15` / `s10*15` / `l10*15` | هزینه تمام‌شده چاپ / شاسی / لمینت برای ما |
| `f_...` | فقط فایل |
